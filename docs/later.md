# Deferred work (not in MVP)

Stretch features from the brief, allowed only after all seven gates pass:

- Multi-week class series

- Pricing optimization
- Spanish translation

Model extensions deliberately deferred:

- Partial-session weather cancellation for hybrid events (MVP cancels the whole event)
- Simulating a second (rain) date
- Correlated inputs (for example weather and no-shows); independent row-level supply-cost sampling
- Stochastic vendor count / vendor dropout for fairs (qualitative risk only in MVP)
- Prepaid per-attendee add-ons (pre-sale quantities are not modeled)
- Same-day sequencing of event-day tasks; critical-path analysis
- Actual expenditure tracking against the spending limit
- Mean-entry for triangular distributions (derive mode = 3·mean − low − high)
